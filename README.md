# CircularPrime
Java program that determines every circular prime up to a given input.

**Note: This program should not be used with large inputs (larger than around 200,000)**

##Definitions
- A cycle of a number is any number that is formed by removing the first digit of the number and adding it at the end.
  The number 7231 has the following cycles:
    > 7231
    
    > 2317
    
    > 3172
    
    > 1723
    
- A circular prime is any number such that each of its cycles are prime.
